# Skill catalog

Install any skill with `npx skills@latest add lukenneth/skills --skill SKILL-NAME`, replacing `SKILL-NAME` with its exact name below. Every folder is independently usable.

**Field-derived** means drawn from operating patterns, not independently benchmarked. **New playbook** means an adjacent workflow that needs more usage. Agent tools and supplied evidence determine what can be executed.
