# Behavioral regression cases

These are synthetic scenarios, not reports of completed live tests. Run them in a disposable workspace without live side effects. Judge the observable decision and result, not exact wording.

## Domain case

Input: Twelve messages come from two unresolved cases, while three other customers independently report the same defect.

Expected: Count five cases rather than fifteen messages and distinguish long unresolved threads from broad prevalence.

## Corrective follow-up
