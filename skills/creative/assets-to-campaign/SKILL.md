# Assets To Campaign

Use the user's existing project context, policies and tools. Ask only for missing information that materially changes the result. Accept authorized exports when live integrations are unavailable; distinguish unavailable evidence from negative evidence. Follow the requested depth: discussion and audit do not authorize implementation or external actions. Keep project-specific data in the project rather than this public skill.

At invocation, read [the corrective-feedback loop](references/feedback-loop.md) and [regression cases](references/regression-cases.md). Apply learned corrections below before choosing an approach.

## Workflow

1. Inventory assets without changing originals. Record transcripts, timecodes, speakers, rights/use constraints and supplied factual corrections. Distinguish inspected media from filename-based guesses.

2. Define the audience, product relationship and intended next action. Group material into themes with an actual source-backed story or useful idea. Label clips as standalone, supporting material or insufficient.

3. Choose formats based on the story. A carousel must carry a complete sequential narrative, not thumbnails advertising another asset. Do not insert invented speaker claims or editorial conclusions.

4. Produce the requested drafts with captions, readable framing and platform-appropriate exports. Preserve title-free masters; when testing titles, keep body and caption stable and record the variable changed.

5. Inspect the rendered outputs and audio/caption alignment. Separate source library, drafts and reviewed deliverables. Provide a review gallery or manifest accepting per-post status, timestamps/slide references and edit notes.

6. Apply feedback to the affected concept or execution, then re-render and recheck. Attractive packaging does not fix an irrelevant concept. Publication requires the user’s actual authorization.

## Deliverable

Campaign map, source-linked post manifest, requested rendered drafts, captions and an editing-feedback surface.

## Example request

> Use $assets-to-campaign: Turn this event footage into cohesive campaigns and post-ready drafts.
