# Recommendation coverage

All 26 named or described workflow recommendations are implemented as individual skills in the five categories listed in the README and catalog.

The first operational shortlist maps directly to investigate-customer, prepare-dispute-evidence, business-health-review, triage-production-alerts, review-acquisition-experiment, find-support-friction and reconcile-delivery.

The consumer-app shortlist maps directly to polish-mobile-flow, refresh-social-proof, build-lead-magnet-funnel, assets-to-campaign, test-creative-hooks, prepare-mobile-release, roll-out-brand-update, prepare-growth-brief, update-live-content and diagnose-user-journey.

The exploratory onboarding, paywall, lifecycle and retention candidates are included as audit-onboarding, review-paywall, audit-lifecycle-messaging and plan-retention-experiment. Contractor delivery and the previously conditional batch-access audit are included as review-contractor-delivery and reconcile-subscription-access. These six are labeled initial-playbook rather than implying proven repeated execution.

The earlier mobile-compatibility, hook-engine and journal-to-video recommendations complete the collection. Generic PR review is not duplicated: the recommended distinctive behavior is review-mobile-compatibility. Reference-led UI polish maps to polish-mobile-flow; product-content lead magnets map to build-lead-magnet-funnel. Hook testing remains separately usable as requested, while campaign production explains how to use that technique within a batch.

Each skill owns its feedback-loop reference and behavioral cases, so copying one directory preserves the complete workflow and self-improvement instructions. No skill requires another skill to be installed.
